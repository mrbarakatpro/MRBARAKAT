# موقع مطعم فريسكا - البحرين | Fresca Restaurant Bahrain

الموقع الرسمي لمطعم فريسكا الفاخر في ضاحية السيف، مملكة البحرين.
يتضمن الموقع:
- الصفحة الرئيسية (الهيدر بنسبة 50% شفافية، زر استكشف المنيو، زر احجز طاولتك، إحصائيات)
- هوية فريسكا واستعراض المجلس الرئيسي - فرع السيف بالحجم المصغر الأنيق
- معرض الصور بنظام سلايد شو متحرك في صف واحد
- صفحة المنيو التفاعلية المنفصلة مع خيارات الطلب وتصفية الأصناف
- لوحة تحكم إدارية احترافية لتعديل النصوص ورفع الصور وإدارة الحجوزات والمنيو

## طريقة التشغيل محلياً:

1. فك ضغط الملف
2. افتح مجلد المشروع في الـ Terminal
3. قم بتثبيت الاعتماديات:
```bash
npm install
```
4. قم بتشغيل خادم التطوير:
```bash
npm run dev
```
5. افتح الرابط في المتصفح:
```
http://localhost:3000
```

## لبناء نسخة الإنتاج:
```bash
npm run build
```
